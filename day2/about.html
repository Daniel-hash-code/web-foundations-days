About QuickNotes

QuickNotes is a simple tool for capturing and organizing your ideas. It helps you keep track of your thoughts, tasks and reminders in one convenient place.

How to use QuickNotes

  1. Visit the homepage
  2. Type your idea into the note input box
  3. Click the "Add note" button to save the note
  4. View your saved notes in the "Your notes" section

Features

  • Easy to use interface
  • Quickly capture your thoughts
  • View all your notes in one place

Keyboard Shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save note
Esc Cancel
